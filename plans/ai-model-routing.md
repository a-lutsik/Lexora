# AI-модели в Lexora: одна модель или три? — план

Дата: 03.10.2026. Цены и ID моделей проверены на эту дату (источники в конце) — перед релизом сверить заново.
Связанные документы: [аудит](../docs/audit/2026-10-03-lexora-audit.md), [упрощение настройки AI](./ai-setup-simplification.md).

## 1. Рекомендация

**Ни «одна модель на всё», ни «три независимые настройки».** Лучший вариант для Lexora —
**один ключ провайдера + маршрутизация по ролям**:

- пользователь видит **три роли**: «Текст», «Картинки», «Голос» (плюс опциональная платная «Иллюстрации»);
- выбирает **пакет** («Gemini», «OpenAI», «Бесплатно», «Локально»), и пакет сам подставляет в каждую роль подходящую модель того же провайдера;
- в расширенном режиме роль можно переназначить на другую модель или другого провайдера (например, бесплатный ASR от Groq + текст от Gemini).

Почему не одна модель:
1. **Живой диалог — другой класс модели.** Нужна потоковая модель «речь → речь» (Gemini 3.8 Live, `gpt-realtime-2.1-mini`)
   с WebSocket/WebRTC, перебиванием и задержкой меньше секунды. Обычная LLM в цепочке «ASR → LLM → TTS» даёт 3–6 с на реплику.
2. **Задачи требуют разного.** Перевод слова в popup — минимальная задержка и цена; OCR — качество зрения; документы и письмо —
   качество текста. Даже у одного вендора оптимальные модели разные.
3. **Текущая схема «одна модель» уже ломает продукт:** дефолтная текстовая модель не умеет картинки и аудио, а общий fallback
   падает так же (аудит, S1-3 и S2-9).

Почему не три независимых провайдера по умолчанию: три аккаунта, три ключа, три счёта — именно эту боль решает
`ai-setup-simplification.md` («один ключ на всё»). Смешивание оставляем как опцию для продвинутых пользователей.

## 3. Сравнение вариантов

| Критерий | A. Одна модель на всё | B. Три независимые модели | **C. Один ключ + роли** |
|---|---|---|---|
| Настройка для новичка | 1 ключ | 3 ключа | 1 ключ |
| Живой диалог | Нет (только «по очереди») | Да, при отдельной voice-модели | Да (Live/Realtime-модель того же вендора) |
| Цена | Переплата: дорогая модель на простых задачах | Оптимально | Оптимально |
| Отказоустойчивость | Одна точка отказа | Изоляция ролей | Изоляция ролей + fallback по возможностям |
| Офлайн/локально | Сложно | Возможно | Пакет «Локально» |
| Сложность кода | Низкая (как сейчас) | Высокая | Средняя (роутер + каталог) |

|---|---|---|---|---|

| Текст — качество (документы, письмо, объяснения) | `gemini-3.8-flash` ($0.75 / $3.75) | `gpt-6.1-sol` | Gemini free tier (`gemini-3.8-flash`) | Ollama `gemma-4` |
| Картинки — OCR и перевод | `gemini-3.8-flash` | `gpt-6-luna` (принимает изображения) | Gemini free tier; альтернатива — `google/gemma-4-31b-it:free` в OpenRouter | Ollama `gemma-4` (vision) |
| Голос — распознавание и перевод аудио | `gemini-3.8-flash` (аудио нативно: webm, m4a, wav) | `gpt-transcribe` | Groq `whisper-large-v3-turbo` | whisper.cpp |
| Голос — живой диалог | `gemini-3.8-live` (≈ $0.005/мин вход, $0.018/мин выход) | `gpt-realtime-2.1-mini`; синхронный перевод — `gpt-realtime-translate` | Цепочка Groq ASR + текст Gemini free + системный TTS | Цепочка: whisper.cpp + gemma-4 + `say` |
| Голос — озвучка | `gemini-3.8-flash-lite-tts` | `gpt-4o-mini-tts` | Системный голос macOS | Системный голос macOS |
| Иллюстрации (опционально, платно) | `gemini-3.1-flash-lite-image` (≈ $0.034 за картинку, бесплатного тарифа нет) | `gpt-image-2.5-flare` | Wikimedia (без генерации) | Wikimedia / без картинок |

Рекомендуемый пакет по умолчанию — **«Gemini»**: один бесплатный ключ закрывает текст, OCR, понимание аудио и живой диалог
(в лимитах бесплатного тарифа); платить нужно только за иллюстрации, и только если пользователь их включит.

Ориентир стоимости для активного ученика в месяц (оценка по опубликованным ценам, не измерение):
1500 запросов в popup на `3.5-flash-lite` ≈ $0.9; 100 картинок OCR на `3.8-flash` ≈ $0.3; 2 часа диалога на `3.8-live` ≈ $1.5–3.
Тот же диалог на `gpt-realtime-2.1-mini` ≈ $2–4, на флагманском `gpt-realtime-2.1` ≈ $7–12.

## 5. Целевая архитектура

1. **Роли вместо одной модели.** `ModelRole = TextFast | TextQuality | VisionOcr | SpeechToText | RealtimeVoice | Tts | ImageGen`.
   Маршрут роли — цепочка `primary → fallback…` (`provider`, `model`).
2. **Разделить «божественный» трейт** `AIProvider` (15 методов) на узкие: `TextModel`, `VisionModel`, `SpeechToText`,
   `TextToSpeech`, `RealtimeVoice`, `ImageGenerator`. Провайдер реализует только то, что умеет, — без методов-заглушек с ошибкой.
3. **Каталог возможностей.** Статический JSON в репозитории (модальности, JSON-режим, поддержка `temperature`, лимит вывода,
   стриминг аудио, цена) + проверка доступности в рантайме (OpenRouter `/models` и `/endpoints`, список моделей провайдера по ключу).
   Модели «без провайдеров» помечаются в Настройках с предложением замены; эфемерные `:free`-ID никогда не ставятся дефолтом.
4. **Fallback по возможностям.** Ошибки классифицируются: «нет возможности» — сразу следующая модель роли; «квота/429» —
   backoff, затем следующая; «авторизация» — стоп и понятное сообщение. Таймаут задаётся на роль.
5. **Local-first.** Локальное определение языка (например, crate `whatlang`) до обращения к кэшу, чтобы `auto` в popup не обходил SQLite;
   офлайн-профиль отвечает из словаря. SRS детерминирован: AI только объясняет ошибку, оценку не меняет.
6. **Живой диалог.** Сессия проксируется через Rust: WebSocket к Gemini Live или OpenAI Realtime, фронтенд стримит 16 кГц PCM
   через Tauri channel, ответ проигрывается потоком; ключ не покидает бэкенд (вариант с WebRTC — эфемерный токен от бэкенда).
   Перебивание (barge-in), транскрипты обеих сторон в БД, оценка реплики — асинхронно отдельной дешёвой текстовой моделью.
7. **Живой перевод речи.** Потоковое распознавание (Live API, `gpt-live-transcribe`) или `gpt-realtime-translate`;
   переводятся только новые финальные сегменты, а не весь транскрипт.
8. **Произношение.** Оценка по тексту распознавания не «слышит» произношение. Нужна аудио-модель (Gemini с аудиовходом) или
   специализированный сервис оценки произношения.
9. **Деньги.** Месячный бюджет на роль, счётчики в БД, подтверждение пакетных операций со сметой, ограничитель параллелизма
   (семафор) для фоновых задач.
10. **Хранилище настроек.** Таблица `model_route(role, position, provider, model, enabled)`; миграция из `ai_provider/ai_model`
    недеструктивная: выбор пользователя переносится в роль «Текст», остальные роли заполняются из пакета провайдера.

## 6. План по фазам

| Фаза | Что делаем | Готово, когда |
|---|---|---|
| 0. Предпосылки (из аудита) | S1-1 (обрезка строки), S1-3 (рабочий дефолт + условные миграции), S1-4 (нет enrich при загрузке паков, очередь с лимитом) | Тест с кириллицей зелёный; свежая установка переводит; загрузка Top 5000 не создаёт фоновых задач картинок |
| 1. Роли и роутер (бэкенд) | `ModelRole`, узкие трейты, каталог, классификация ошибок, таймауты, миграция V023 `model_route` | Юнит-тесты роутера: OCR-запрос пропускает текстовую модель и идёт в vision-модель; авторизационная ошибка не уходит в fallback |
| 2. Пакеты и Настройки | Пакеты «Gemini/OpenAI/Бесплатно/Локально»; три роли в UI с индикатором готовности и тестом на роль; расширенный режим — модель на роль | E2E: выбор пакета заполняет все роли; модель без endpoints показывается недоступной |
| 3. Аудио | Роль ASR; `input_audio` для OpenRouter; нормализация форматов (webm/m4a/wav); инкрементальный живой перевод | Перевод аудио работает в пакетах Gemini, OpenAI и Бесплатно; цена живого перевода растёт линейно |
| 4. Живой диалог | Прокси-сессия Live/Realtime в Rust, стрим PCM, barge-in, асинхронная оценка | Задержка ответа < 1,5 с (p50) на Gemini Live; разговор продолжается при ошибке оценщика |
| 5. Картинки и озвучка | Уменьшение изображений до лимитов, HEIC → JPEG, координаты блоков; роль TTS (Gemini TTS / `gpt-4o-mini-tts`); панель расходов | OCR фото 12 МП проходит лимит 20 МБ; озвучка откатывается на системный голос при ошибке |

## 7. Риски и открытые вопросы
- Каталоги моделей меняются ежемесячно — нужен процесс обновления каталога и проверка доступности при старте.
- Условия бесплатных тарифов меняются; в UI показывать лимиты и предупреждать о переходе на платный тариф.
- Приватность: аудио и картинки уходят провайдеру — согласие на уровне роли, офлайн-пакет как альтернатива.
- WebRTC в WKWebView поддерживается, но прокси через Rust надёжнее и не раскрывает ключ — рекомендую его.

## 8. Решения (приняты 2026-10-04)
1. Пакет по умолчанию — **Gemini** (один бесплатный ключ).
2. Смешивание провайдеров по ролям — **только в расширенном режиме** («Расширенные» в Настройки → AI-модели);
   в обычном UI — пакет, готовность ролей и «Проверить».
3. Синхронный перевод «речь → речь» — **отдельная функция**: вкладка «Live Interpreter» (Gemini Live Translate).
