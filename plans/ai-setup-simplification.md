# Упрощение настройки AI: «Сценарии Бесплатно / Платно»

## Проблема

Обычному пользователю нужно разобраться в инженерной форме из ~1750 строк
([`SettingsPage.tsx`](../src/pages/settings/SettingsPage.tsx)), чтобы заработали три вещи:
перевод, генерация картинок и аудио. Для этого приходится выбирать: провайдер → модель →
API-ключ (+ Account ID для Cloudflare), отдельно fallback-провайдер → ключ, отдельно модель
картинок → ключ — и у каждого своя кнопка «проверить соединение». Онбординга при первом
запуске нет.

Текущие факты из кода:
- Перевод = `aiProvider` + `aiModel` + ключ; «офлайн» = встроенный словарь без ключей.
- Картинки = отдельные `imageModel`/fallback ([`imageModels.ts`](../src/lib/imageModels.ts)): Cloudflare FLUX (free daily) либо платные Gemini/OpenAI.
- Аудио = только системный TTS macOS ([`system.rs`](../src-tauri/src/providers/tts/system.rs)); `OpenAITTSProvider` ([`openai_tts.rs`](../src-tauri/src/providers/tts/openai_tts.rs)) написан, но не подключён; `alloy` трактуется как плейсхолдер ([`voices.rs`](../src-tauri/src/providers/tts/voices.rs)).
- Cloudflare — единственный провайдер, чей один бесплатный ключ даёт и перевод, и ИИ-картинки.
- Один платный ключ OpenAI способен закрыть перевод + картинки + нейро-озвучку.

## Решение: 2 сценария + «Статус AI»

Добавляем мастер первого запуска с двумя карточками-сценариями и упрощённый статус в
Настройках. Полная старая форма остаётся за «Показать расширенные настройки»
(progressive disclosure, см. AGENTS.md).

### Сценарий A — «Бесплатно» (рекомендован для старта)

Показываем пользователю преимущества простым языком, затем 2 под-пути:

- **A1. Без ключей — работает сразу.** Встроенный офлайн-словарь, системный TTS,
  Wikimedia/seed-картинки. Преимущество: 0 минут на регистрацию, 0 ₽, полная приватность и
  работа без интернета. Ограничение: перевод по словарю без ИИ-обогащений (объяснения,
  диалог, письмо, генерация картинок).
- **A2. Один бесплатный ключ Cloudflare.** Токен + Account ID → перевод (Llama) и
  ИИ-картинки (FLUX, бесплатный дневной лимит), аудио остаётся системным. Преимущество:
  настоящий ИИ-перевод и генерация картинок за 0 ₽ одним аккаунтом. Ограничение: суточный
  лимит free-tier, без нейро-голоса.

Преимущество сценария «Бесплатно»: нулевая стоимость и быстрый старт «в один экран», а
богатые ИИ-функции включаются позже одним ключом без «переучивания».

### Сценарий B — «Платно» — «Один ключ для всего»

- **B1. OpenAI:** вставка одного ключа `sk-…` → автоматически прописываются перевод
  (gpt-4o-mini), картинки (gpt-image-1), нейро-озвучка (OpenAI TTS, при доработке фабрики
  TTS), отключается head-ache с fallback. **B2. Gemini** (`AIza…`) — аналогично, картинки
  через Gemini Image.

Преимущество: максимум качества и предсказуемости — единый биллинг, единый ключ, меньше
лимитов, доступны ИИ-ассистенты (Writing, Dialogue, объяснения ошибок). Недостаток:
небольшая плата за использование (обычно $1–5/мес).

## Архитектура

Новое поле сценария: `setup_profile` (`zero | free-cloudflare | paid-openai | paid-gemini | advanced | NULL`).
NULL = пользователь ещё не выбирал (показываем мастер); `advanced` = выбрал «оставить как есть».

Индикаторы возможностей (`computeAiReadiness`) — чистая TS-функция по `settings + apiKeysStatus`:
- `translate`: готов, если `offline`/словарь либо ключ провайдера (+Account ID для CF);
- `images`: «ИИ-картинки» готовы, если у выбранной image-модели есть ключ; «базовые» (Wikimedia/seed) — всегда;
- `audio`: системный TTS — всегда; «нейро-голос» — при OpenAI-ключе + `tts_engine='openai'`.

Пресеты живут во фронтенде ([`setupPresets.ts`](../src/lib/setupPresets.ts)) как полные
`AppSettings` (единый источник моделей уже в TS). Бэкенд получает только атомарную команду
`apply_setup_preset` (одна транзакция: settings + ключ + профиль) — принцип «no silent data loss».

### Точки входа
1. Первый запуск: [`SetupWizard.tsx`](../src/components/setup/SetupWizard.tsx) поверх
   роутера в [`App.tsx`](../src/App.tsx), пока `setupProfile == null` (после загрузки настроек).
2. Настройки → блок «Статус AI» в шапке ([`SettingsPage.tsx`](../src/pages/settings/SettingsPage.tsx)) с
   чипами Перевод/Картинки/Аудио и кнопкой «Сменить сценарий» (повторно открывает мастер).

### Файлы
- Бэкенд: `migrations/V011__setup_profile.sql` (новые колонки), `repos/settings.rs`,
  `commands/settings.rs` (DTO + `apply_setup_preset`), `commands/mod.rs`; (опц.)
  `providers/tts/mod.rs` фабрика + `commands/media.rs`, `services.rs` для нейро-озвучки.
- Фронтенд: `lib/setupProfile.ts` (типы, детект ключа, readiness), `lib/setupPresets.ts`,
  `lib/types.ts` (AppSettings + `setup_profile`/`tts_engine`), `lib/ipc.ts`,
  `components/setup/SetupWizard.tsx` + `setup.css`, `App.tsx`, `pages/settings/SettingsPage.tsx`
  (+ вынос расширенной формы в подкомпонент), `styles/tokens.css` при необходимости.

### Совместимость
Существующие пользователи: если ключи уже есть, мастер не навязываем — в Настройках
показываем разовый баннер «Хотите проще? Выберите готовый сценарий». Настройки, не
относящиеся к AI (стикеры, горячие клавиши, приватность), в мастере не трогаем — они
остаются в расширенной форме.
