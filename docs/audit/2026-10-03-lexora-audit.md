# Lexora — аудит багов и UI (03.10.2026)

Режим: **только анализ**, код приложения не менялся. План по AI-моделям вынесен в отдельный документ
[`plans/ai-model-routing.md`](../../plans/ai-model-routing.md).

Статусы находок:
- **Воспроизведено** — увидел дефект в работающем UI (Vite + мок Tauri IPC), в тесте, скрипте или на копии вашей БД.
- **Подтверждено кодом** — прослежен путь «триггер → эффект» по коду, внешние факты проверены по исходникам/документации.
- **Вероятно** — правдоподобный риск, для подтверждения нужен живой запуск или реальный API.

Серьёзность: **S1** — падение, потеря данных/денег, ключевая функция не работает; **S2** — заметный дефект основной
функции; **S3** — ограниченный дефект/риск; **S4** — косметика и гигиена.

## 0. Главное

Найдено **4 критичных (S1)**, **21 серьёзный (S2)**, **~30 средних (S3)** и **~8 мелких (S4)** дефектов.
Самое важное — в порядке исправления:

1. **Приложение падает целиком** при любом невалидном JSON-ответе модели с кириллицей: срез строки `&text[..300]`
   по байтам + `panic = "abort"` в release. Воспроизведено (exit 134).
2. **Режим Flashcards (режим по умолчанию) не сохраняет оценки в SRS** — ни одного IPC-вызова за сессию. Воспроизведено в UI.
3. **AI по умолчанию не работает**: миграция V020 принудительно ставит всем `minimax/minimax-m3:free` (+ fallback
   `minimax-m2.7:free`), а у обеих моделей в OpenRouter сейчас **0 доступных провайдеров**. Проверено через API OpenRouter.
4. **Загрузка пака запускает неограниченный фоновый «шторм» LLM-вызовов и генераций картинок** (даже в режиме «без картинок»),
   кнопка в UI всегда грузит «с картинками» — для Top 5000 это тысячи платных генераций без предупреждения.
5. **Нельзя вернуть удалённое слово**: `add_to_vocabulary` не снимает `deleted_at` → ошибка «not found», а popup её не показывает. Воспроизведено.
6. В вашей реальной БД пак **Top 5000 помечен `ready`, но перевод есть только у 285 из 5000 слов** — ошибки перевода глотаются.
7. **Ключи API лежат открытым текстом** (`api-keys.json`, права `0644`), а ключ Gemini **утекает в текст ошибок** (ключ в URL, reqwest печатает URL).
8. **Ловушка SM-2**: после серии «Hard» интервал навсегда залипает на 1 дне, даже при правильных ответах.
9. **UI-потоки, блокирующие пользователя**: белый экран popup на «C++», бесконечный цикл 1000+ IPC-вызовов в «Диалоге»,
   «вечный» оверлей карточки слова, в словаре видно только 50 слов из 5282.
10. **Архитектура AI**: одна модель на текст + OCR + аудио + диалог, поэтому дефолтная текстовая модель ломает перевод картинок,
    аудио и голосовой диалог. Решение — в плане по моделям.

## 2. Критичные (S1)

### S1-1. Падение всего приложения на невалидном JSON от модели — Воспроизведено
- **Где:** `src-tauri/src/providers/ai/mod.rs:66` (`extract_json`), `src-tauri/Cargo.toml:75` (`panic = "abort"`).
- **Триггер → эффект:** модель вернула не-JSON или обрезанный JSON (Cloudflare `max_tokens: 1024`, отказ модели, «рассуждение»
  текстом), ответ длиннее 300 байт и на 300-м байте — середина кириллического символа → `&text[..300]` паникует →
  в release-сборке процесс аварийно завершается. 71 место вызова — затронуты все AI-функции.
- **Доказательство:** скрипт с точной копией ветки ошибки → `end byte index 300 is not a char boundary`, **exit code 134**.
  Тест `extract_json_error_message_truncates_long_responses` использует только ASCII и дефект не ловит.
- **Направление:** обрезать по символам (`chars().take(300)`), добавить тест с кириллицей; рассмотреть `panic = "unwind"` + перехват паник в командах.

### S1-2. Flashcards (режим по умолчанию) не обновляет SRS — Воспроизведено
- **Где:** `src/pages/study/StudyPage.tsx:123–126`, `src/pages/study/modes/FlashcardMode.tsx` (нет вызова `useEvaluateAnswer`).
- **Триггер → эффект:** любая сессия Flashcards: оценки Again/Hard/Good/Easy пишутся только в Zustand-статистику;
  `review_state` и `review_event` не меняются, расписание не двигается. Режим описан как «SM-2 spaced repetition».
- **Доказательство:** в UI прошёл карточку и нажал «Good» — лог IPC пуст, экран «Session Complete». В вашей БД при
  5282 словах всего **43** события повторения.
- **Направление:** вызывать `evaluate_answer` (или отдельную команду «grade без проверки ответа») при оценке.

### S1-3. AI по умолчанию не работает; миграция перезаписывает выбор пользователя — Подтверждено (API + код)
- **Где:** `src-tauri/src/db/migrations/V020__openrouter_default_ai.sql`, `commands/settings.rs:68–81`, `pages/settings/SettingsPage.tsx:72–79`.
- **Факты на 03.10.2026:** `minimax/minimax-m3:free` и `minimax/minimax-m2.7:free` есть в каталоге, но у обоих
  **0 endpoints** (платные `minimax/minimax-m3` — 13 провайдеров). Запросы получают «No endpoints found».
  Также недоступны `deepseek/deepseek-r1:free`, `google/gemini-2.5-flash:free`, `z-ai/glm-5.2:free` из списка в Настройках
  и `meta-llama/llama-3.3-70b-instruct:free` — дефолт `CustomOpenAIProvider`.
- **Эффект:** на конфигурации по умолчанию не работают перевод, обогащение, письмо, диалог, OCR; основная и резервная модели падают одинаково.
- **Плюс:** V020 — безусловный `UPDATE user_settings … WHERE id = 1`: при обновлении у любого пользователя перезаписывается
  выбранный провайдер/модель/fallback (в вашей БД сейчас ровно значения из V020).
- **Направление:** не хардкодить эфемерные `:free`-ID как дефолт; проверять доступность модели при старте и в Настройках;
  миграции настроек делать условными (`WHERE ai_provider = '<старый дефолт>'`).

### S1-4. Загрузка пака: неограниченный фон LLM и генерации картинок, без согласия на расходы — Подтверждено кодом
- **Где:** `db/packs.rs:301` (`let _ = translate_text_inner(...)` для каждого слова), `commands/translate.rs:282` (каждый
  живой перевод **всегда** вызывает `spawn_enrich`), `providers/media/mnemonic.rs:334–399` (сначала AI-генерация,
  сток — только если генерация не настроена или упала), `pages/collections/CollectionsPage.tsx:59` (`loadSystemPack(id, true)` — всегда «с картинками»).
- **Триггер → эффект:** «Load into database» у Top 5000 (в CSV нет переводов) → ~5000 последовательных переводов, и
  на каждый — **не ожидаемая** фоновая задача: обогащение (LLM) + мнемоника (2 LLM) + генерация картинки. Задачи
  копятся параллельно без ограничения → шторм 429 и, при настроенной платной модели (OpenAI image, Gemini image —
  бесплатного тарифа нет, ~$0.045 за картинку), счёт на сотни долларов. При `with_images = true` возможна двойная
  генерация на слово (цикл и enrich запускают пайплайн одновременно).
- **Данные:** в вашей БД 3407 картинок Wikimedia + 46 сгенерированных; генерация почти везде упала, что и спасло от счёта.
- **Направление:** при загрузке паков не вызывать `spawn_enrich`; очередь с ограничением параллелизма и бюджетом;
  явный выбор «с картинками/без» и предупреждение о стоимости.

## 3. Серьёзные (S2)

### Данные и словарь
- **S2-1. Нельзя вернуть удалённое слово** — Воспроизведено (SQL + UI). `commands/vocabulary.rs:651`: `INSERT OR IGNORE`
  не снимает `deleted_at`, затем `get_vocabulary_entry_by_id` фильтрует `deleted_at IS NULL` → «Not found: Vocabulary entry N not found».
  Реально достижимо: отключение коллекции мягко удаляет её слова, после чего любое из них нельзя добавить из popup.
  Протестированный `VocabularyRepo::add` (с `ON CONFLICT … deleted_at = NULL`) команда не использует. Команда к тому же
  выполняет три записи без транзакции, хотя комментарий утверждает обратное.
- **S2-2. Пак «ready» без переводов** — Воспроизведено на вашей БД: Top 5000 = 5000 слов, перевод есть у **285**.
  `packs.rs:301` игнорирует ошибки, `packs.rs:358` всегда ставит `ready`. В карточках и стикерах «No translation».
- **S2-3. Список словаря показывает только 50 слов** — Воспроизведено (UI: «5 282 words», список заканчивается на word50).
  `lib/constants.ts:32` `perPage: 50`, страница всегда 1, нет пагинации и виртуализации (AGENTS §11 требует `@tanstack/react-virtual`).
- **S2-4. В UI нет удаления слова** — Подтверждено кодом: `useRemoveFromVocabulary` нигде не используется.

### Учебный процесс (SRS)
- **S2-5. Ловушка «Hard»** — Подтверждено симуляцией точной копии `srs/algorithm.rs:47–59`: `(interval * 1.2) as i64`
  не растит интервалы 1–4, но увеличивает `repetitions` и снижает ease. После 8 «Hard» (оценщик ставит 2 за опечатку
  в одну букву) ease = 1.3, и далее «Good» даёт `round(1 × 1.3) = 1` — интервал **навсегда 1 день**; выйти можно только
  через «Easy», которую режим Typing никогда не ставит.
- **S2-6. Расписание зависит от ответа LLM** — Подтверждено кодом. `commands/study.rs:85`: при эвристической оценке < 3
  результат `explain_error` **заменяет** оценку целиком (`grade` не ограничен, `as u8`, промпт разрешает 4 = «easy»
  для неверного ответа). Нарушен принцип детерминированного SRS (AGENTS §0.4, §7). Кнопка «Забыл» в стикере
  тоже уходит в AI. Объяснение генерируется на языке карточки, а не на языке интерфейса.
- **S2-7. Повтор только что пройденных карточек** — Подтверждено кодом. `hooks/useStudyQueue.ts:38`: после оценки
  не инвалидируется `study-queue`; `StudyPage` остаётся смонтирован, и «Start Session» после завершения берёт
  кэшированную очередь — те же карточки повторяются вне расписания, интервалы раздуваются (1 → 4 → 10 за минуты).
- **S2-8. Выдуманный контент в обучении** — Воспроизведено (скриншот 01). `FlashcardMode.tsx:32` — одни и те же три
  русских дистрактора для **каждого** слова, «перемешивание» по алфавиту; панель «AI Explanation» показывает
  захардкоженный текст «From Latin roots…» (для «apple» это ещё и фактически неверно) и «appears often in academic &
  professional speech»; ранг частоты `?? 1847`; на кнопках оценок фиксированные «1d/2d/4d/8d», не связанные с SM-2;
  при отсутствии перевода правильный вариант — строка «No translation».

### AI-провайдеры
- **S2-9. Одна модель на всё ломает OCR/аудио/диалог** — Подтверждено кодом. `providers/ai/mod.rs:1573–1735`:
  одна пара `ai_provider/ai_model` и общий fallback для текста, картинок, аудио и диалога. OpenRouter: `custom.rs:526`
  отказывает в аудио, хотя OpenRouter принимает `input_audio` для аудиомоделей; картинка уходит в текстовую модель.
  Cloudflare: OCR и речь — ошибки, хотя в Workers AI есть Whisper и Llama 3.2 Vision. Anthropic: без аудио.
  На дефолтной конфигурации голосовой диалог и перевод аудио невозможны.
- **S2-10. Устаревающие модели** — Подтверждено документацией. Пресет OpenAI использует `gpt-image-1` (**отключение
  01.12.2026**); транскрипция — `whisper-1` (отключение 26.02.2027); TTS — `tts-1` (06.01.2027). В Настройках есть
  `gemini-1.5-flash` (линейка 1.5 снята) и устаревший Groq `qwen/qwen3.6-27b` (сейчас Qwen3.8-27B preview).
- **S2-11. Живой перевод речи: квадратичная стоимость** — Подтверждено кодом. `hooks/useLiveSpeechTranslate.ts:98`:
  каждые 2,2 с — ASR чанка + (для OpenAI/Groq) лишний перевод внутри `translate_audio` + перевод **всего** накопленного
  транскрипта промптом для отдельных слов (IPA, синонимы). Голосовая реплика в диалоге (`commands/dialogue.rs:184`)
  тоже платит за ненужный перевод en→en.

### Безопасность и приватность
- **S2-12. Ключи API открытым текстом** — Воспроизведено (файл на диске). `api-keys.json` (JSON, права `0644`) хранит
  ключи groq/cloudflare/gemini/openrouter. `tauri-plugin-store` не шифрует; AGENTS §9 требует хранилище ОС. Направление: macOS Keychain.
- **S2-13. Ключ Gemini утекает в сообщения об ошибках** — Подтверждено кодом и исходником зависимости:
  `providers/ai/gemini.rs:35` и `media/image_gen.rs:449` передают ключ в `?key=`; `reqwest 0.12.28`
  (`src/error.rs:268`) дописывает `for url (…)` в текст ошибки; код делает `e.to_string()`. Любой сетевой сбой
  (например, офлайн) покажет `…?key=AIza…` в UI и логах. Направление: заголовок `x-goog-api-key` или `e.without_url()`.

### Интеграция с ОС
- **S2-14. Захват выделения уничтожает буфер обмена** — Подтверждено кодом. `hotkeys.rs:508–530`: если AX-выделение
  недоступно (Chrome, Electron, VS Code), сохраняется только текстовый буфер (обрезанный до 8000 символов и обрезанный
  по пробелам), затем `clearContents()` и запись обратно → скопированные картинка, файл или RTF **стираются**, длинный текст
  урезается.

- **S2-17. «Вечный» оверлей карточки слова** — Воспроизведено (скриншот 04). `WordDetail.tsx:169`: при ошибке загрузки

## 4. Средние (S3)

**SRS и учёба**
- `srs/queue.rs:69–92`: флаг `include_new = false` не работает — новые слова получают `due_at = now` и попадают в ветку «due»

**Словарь и данные**
- Поиск: `LOWER()` в SQLite складывает только ASCII → «Кот» не находит «кот»; команда `list_vocabulary` не ищет по переводам,
  игнорирует `sortBy` и `collectionId` (полноценная версия в `VocabularyRepo::list` не подключена); `%`/`_` не экранируются.
- Пакетный импорт: больше 100 строк до дедупликации — ошибка, а файл молча обрезается до 100 слов; строки длиннее 200 символов пропадают без сообщения.
- Отключение коллекции без подтверждения мягко удаляет все её слова, включая изученные и избранные.
- Пользовательские коллекции создать можно, но добавить в них слова нельзя (нет IPC и UI).
- Статус пака `loading` не сбрасывается при старте: если приложение закрыть во время загрузки и слов 0, кнопка навсегда заблокирована.
- Сид-переводы из CSV — русские, но сохраняются под текущий язык интерфейса (например, `de`).
- Экспорт теряет домены переводов, примеры, синонимы, историю повторений, коллекции; запись файла не атомарна.
- Бэкап делается **после** миграций; `check_integrity` считает «повреждением» любую ошибку (lock, права, IO) и
  карантинит живую БД с откатом на бэкап до суток давности; при каждом старте полный `integrity_check` (быстрее — `quick_check`).
- `CardEnrich`: каждое попадание в кэш при отсутствии картинки заново запускает пайплайн картинки — без кулдауна и дедупликации.

**AI и медиа**
- Нет таймаутов HTTP у всех провайдеров (`Client::new()`) — зависший запрос крутит спиннер бесконечно.
- `cloudflare.rs:48` `max_tokens: 1024` для документов, письма и диалога → обрезанный JSON (и триггер S1-1).
- Текст в Translation Hub и аудиотранскрипты переводятся промптом для одиночных слов (IPA и синонимы целого абзаца).
- Перевод картинок: нет уменьшения изображений (у Gemini лимит запроса 20 МБ), HEIC/TIFF/BMP помечаются как `image/png`;
  при «Save to vocabulary» язык подставляется `en` при Auto, а перевод кладётся в заметки.
- Gemini: `gemini_audio_mime` превращает запись `audio/mp4` (WKWebView на старых macOS) в `audio/mp4`, а Gemini
  принимает `audio/m4a` — **Вероятно**, ошибка формата (проверить живым вызовом). `thinkingLevel: minimal` ставится всем `gemini-3*`, включая Pro-модели.
- OpenAI: `temperature: 0.3` захардкожен — **Вероятно** сломает переход на reasoning-модели, если они не принимают параметр.
- `study.rs:build_ai_provider` дублирует фабрику провайдеров: нет Anthropic, ключи только из env, fallback игнорируется.
- `api_keys.rs:17`: нет `anthropic` → `ANTHROPIC_API_KEY` из README не читается, в статусе ключей Anthropic не виден.
- TTS: при движке OpenAI уходит имя голоса macOS (например, «Samantha») → ошибка без отката на системный голос;
  `afplay` запускается «выстрелил и забыл» — голоса накладываются; на не-macOS `speak` молча ничего не делает.
- Пресет Gemini обещает «перевод и картинки одним ключом» на бесплатном тарифе — у генерации картинок бесплатного тарифа нет.
- Диалог: «оценка произношения» считается по тексту, без аудио; запись сохраняется до ASR — при ошибке остаются сироты-файлы.

**Безопасность и приватность**

- `std::env::set_var` вызывается на пути чтения ключа в многопоточном рантайме — гонка с `getenv` из C-кода.

**ОС-интеграция и окна**
