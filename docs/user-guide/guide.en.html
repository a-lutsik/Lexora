1. About the app and core principles

Lexora is a desktop application (Tauri 2 + React + Rust, SQLite database) for learning foreign languages. You build a personal vocabulary, review words with the SM-2 spaced-repetition algorithm, write and translate texts with AI, practice pronunciation and talk to an AI conversation partner.

Local-first. Vocabulary, reviews and statistics work fully offline. The internet is needed only for AI features (translation, text checking, voice).
Privacy by design. No analytics or telemetry. Data is stored only on your computer; AI usage counters are local too.
Deterministic repetition. The same answers always produce the same next review date (SM-2).
No data loss. All database writes are transactional, integrity is checked at startup, and there are automatic copies and JSON export.

First-run wizard

On first launch, while AI is not configured, the "Как настроить Lexora?" (How to set up Lexora) wizard opens automatically. It picks a model package for you — no need to configure each role by hand. The wizard is in Russian.

  • Free — no card needed. One free Google Gemini key (get it at aistudio.google.com → Get API key) enables AI translation, photo and voice translation, live dialogue and live interpreting. You can also go with no keys at all: built-in dictionary, free photos (Wikimedia) and the system voice. A free Cloudflare Workers AI option is also available.
  • Paid — one OpenAI or Gemini key billed by usage: everything from the free scenario plus AI illustrations for words.

You can change the scenario later: Settings → AI models → "Сменить сценарий" (Change scenario).

3. Quick start in 5 steps

  1. Choose an AI scenario in the wizard (Google Gemini with a free key is recommended) and paste the key.
  2. Set your learning language and translation language: Settings → Language Preferences.
  3. Add words: Vocabulary → Add Word (one by one), Paste list (as a list), or load a ready-made pack in Collections.
  4. Study: Study → choose a mode → Start Session. Rate yourself with Again / Hard / Good / Easy — the app schedules the next review itself.
  5. Turn on the background tools: hotkey ⌘⇧L to translate selected text and ⌘⇧S for stickers (Windows/Linux: Ctrl+Shift+L / Ctrl+Shift+S).
If you do not want to configure AI at all, the app still works: vocabulary, reviews and statistics are fully offline.

4. Interface: navigation

On the left is the sidebar with the main sections. The Study item has a red counter showing how many cards are due today. Settings is at the bottom. You can hide the window: the app stays in the system tray / menu bar.

The interface is dark and works with mouse and keyboard (there is a "Skip to main content" link, visible focus and ARIA labels).

5. Vocabulary — your personal word list

A table of words with columns: Word (word and transcription), Translation, Type (part of speech), Frequency (frequency rank), Status and Due (next review). The list is virtualized — large vocabularies (thousands of words) scroll smoothly.

  • Search by word and translation — the "Search words…" box.
  • Status filters: All · New · Learning · Review · Mature.
  • Study Now — go straight to review.
  • ▶ sound next to a word — text-to-speech (TTS is cached locally).

Word statuses

StatusMeaning
NewWord added, not reviewed yet.
LearningInterval 1–4 days.
ReviewInterval 4–21 days.
MatureInterval over 21 days — the word has stuck.

Adding words

The Add Word button and the arrow next to it open a menu with three ways:

  1. Add one — type a word or phrase and press Translate: Lexora finds the translation, transcription, part of speech, examples and (if enabled) a picture. The "Personal notes" field lets you write context or a mnemonic. Add to Vocabulary saves the word. The translation language is chosen in the window (a per-session setting; it does not change the global one).
  2. Paste list — paste words one per line (up to 100 entries at a time). They are translated in the background.
  3. Upload file — load a word list from a file.

Word card

Clicking a row opens a panel on the right: word, transcription, part of speech, frequency, status, translation and alternatives, illustration, SRS data (Interval, Ease Factor, Repetitions) and personal notes (Save Notes). Also here: favorite (star), Practice pronunciation (jumps to Speak with this word), picture refresh and Remove from vocabulary.

6. Study — spaced repetition (SRS)

The "Study Session" screen shows how many cards are due and offers 8 modes. Choose a mode and press Start Session. At the top is session progress ("Card 1 of 5"); at the bottom — "Due today", "Accuracy" and "Time".

The algorithm

Lexora uses SM-2 — a pure, deterministic function. After each answer a grade is recorded (0 — total blackout … 4 — easy) and the interval, ease factor and next review date are recalculated. A mistake returns the word to a short interval and increases the "lapses" counter, which feeds the "hardest words" list in the statistics.

The 8 modes

ModeHow it works
FlashcardsClassic cards: word → choose a translation from several (or "Show Answer", Space) → self-rating Again / Hard / Good / Easy. A "Context" panel on the right shows an example.
Typing ModeYou see the translation and type the word. Check with Enter; spelling mistakes are explained.
ListeningYou hear the word and type what you heard.
Fill the GapA sentence with a gap; AI can explain the mistake.

Irregular VerbsPractice Past Simple and Past Participle forms.

At the end of a session a summary appears; Back to Study Overview returns to mode selection. "Irregular Verbs" and "Image Association" work with suitable words from your vocabulary (verbs and words with pictures).

7. Writing — writing assistant

Paste a text (up to 8000 characters) and press Check writing. Lexora scores the text (0–100), highlights mistakes, shows a corrected version and explains each issue (category, rule).

  • Apply / Accept all — accept one fix or all. Copy copies the corrected text, Use as input puts it back as the new input.
  • Auto-check (toggle at the top) — check automatically after you stop typing. Uses AI requests.
  • Rewrite — rewrite the text: Clearer, Shorter, More formal, Friendlier, Professional, Simpler.
  • Your Error Patterns — your typical mistakes (e.g. "she go → she goes ×3"). Generate Exercises builds exercises on exactly these.
Writing privacy mode (Settings → Privacy) does not store checked texts and does not collect error patterns.

8. Translate — translation hub

At the top: source language (Auto-Detect by default), the ⇄ swap button, target language and the "Smart" mode. Six tabs:

TabWhat it does

Image & PhotoTranslate pictures and screenshots: drag a file (PNG, JPG, WebP), choose via a dialog or paste from the clipboard with ⌘V. View modes: In-Place Overlay (translation over the image), Side-by-Side, Extracted Text.

9. Speak — pronunciation coach

Four tabs: Practice, Shadowing, Minimal pairs, History. Results are scored 0–100 and per phoneme; the pass mark is 90%.

Practice

Enter a word or phrase (you can set a target IPA transcription). Listen to Model plays the reference pronunciation, Voice selects the voice, Say / Record records (or hold Space). After recording you see "Current Score" and the session total "Total Session Score". Click a problem phoneme to get an articulation tip (e.g. "Close both lips…"). Next Phrase moves on.

Shadowing

The phrase comes from your review queue. Listen to the sample and repeat right after it (Say phrase → "Speak now" → Stop recording); speech waveforms are compared and the result is "Passed" or not.

Minimal pairs

Word pairs that differ by one sound (ship / sheep, /ɪ/ vs /iː/). Listen to both (Listen), then say the target word — you get a match score. The contrast can be chosen in the list at the top right.

History

A list of past attempts with scores; the "Problem sounds" block (your most problematic sounds) is built from them and is also visible in Stats.

10. Dialogue — AI conversation

At the top left are the AI Dialogue and Practice Scenarios tabs. Choose a scenario with a level (e.g. "Coffee Shop in London (B2 Level)"). The AI partner opens the conversation with a first line and plays a role (barista, shop assistant, etc.).

  • Record & send — record a reply by voice: hold Space, release and the reply is sent (Say / Send).
  • Live conversation — live voice dialogue mode (needs a provider with realtime voice — Gemini Live).
  • Type a reply instead — answer in text.
  • On the right — Current Turn Score (score of the reply), Total Session Score (Fluency & Clarity) and Live vocabulary suggestions — useful expressions for the scenario.

11. Collections — word packs

Ready-made ("system") packs for the learning language: Top 5000 Words, Phrasal Verbs, Irregular Verbs, Business English, Academic English, Travel English. A pack must first be loaded into the database, then enabled in SRS:

  1. Load into database — loads the pack's words (about 5000 for Top 5000). The checkbox "Also fetch pictures when loading a pack" additionally fetches pictures (slower; uses the image provider).
  2. Enable in SRS / "Active in SRS" — enable or disable the pack in reviews.

+ New Collection creates your own collection (name and description).

Packs can also be used as a source for desktop stickers (Settings → Stickers).

12. Stats — statistics

  • Total Vocabulary — all words; Accuracy — percentage of correct answers; Mature Words — words with an interval > 21 days; Current Streak — consecutive days with a review.
  • Words Added — added today / this week / this month / total.
  • Activity — Last 30 Days — chart: reviews (blue) and added words (green) per day.
  • Accuracy by Error Type — accuracy by error type (grammar, spelling…).
  • Hardest Words — words with the most mistakes and low accuracy.
  • SRS Mastery Stages — New / Learning / Review / Mature.
  • Writing Mistake Patterns and Pronunciation — typical writing mistakes and problem sounds.

13. Outside the main window

Popup translator

Select text in any app (browser, PDF, notes) and press ⌘⇧L (Windows: Ctrl+Shift+L). A popup opens with the translation, transcription, synonyms, frequency, picture and examples. Text is taken only from the selection, never from the clipboard. The window closes with Esc.

  • + Add Word — save the word to your vocabulary (the button becomes "✓ Added to Vocabulary").
  • 🔊 — playback, bookmark — save to history, Translate/Enter — translate manually entered text.
  • Source/target language and mode ("Auto" / "Smart") can be chosen right in the window.
  • For longer selected text the window works as a built-in AI assistant: you can accept and replace the text in the app (accept and replace).

Desktop stickers

Small translucent cards over your desktop for ambient review. A card shows the word and transcription; the translation is hidden (the eye button reveals it). Rate yourself:

  • Помню ✓ (I remember) — the word is retained; Не помню ✕ (I don't remember) — it comes back sooner; Позже (Later) — postpone. After you answer, the card disappears and is replaced by the next one.
  • Top buttons: playback, show translation, example quote, word-source filter, pin on top, close.

Show/hide all stickers: ⌘⇧S or "Toggle Stickers" in the tray menu. Count, opacity, word sources and quiet hours — Settings → Stickers.

Tray menu

The Lexora icon in the menu bar (macOS) / system tray: Open Lexora, Open Translator (an empty translator window; nothing is taken from the clipboard), Translate Selection, Toggle Stickers, Quit. On macOS, translating selected text is also available via right-click → Services → Lexora.

Writing check in other apps ("like Grammarly")

Enabled in Settings → "Writing check in other apps" (off by default; macOS and Windows; requires the same Accessibility permission).

  • Lexora watches the text field you are typing in. After a ~0.7 s pause the text is sent to the AI provider for a check in the learning language.
  • A badge with the number of suggestions appears at the corner of the field.
  • Clicking the badge opens a panel with fix cards; Apply changes the text right in the field (first just the fragment via Accessibility — formatting and undo are preserved; if the app refuses writes, via the clipboard). If you changed the text after the check, the fix is not applied. Dismiss rejects a suggestion, Esc closes the panel.
  • Not read: password fields, search fields, apps on the exclusion list (password managers, terminals, IDEs — editable in settings), text not in the learning language. Checks are not saved to the database.

14. Configuring the app (Settings)

The settings page is one long screen with a quick-jump bar at the top: AI models · AI usage · Language · Privacy · Writing check · Stickers · Shortcuts · Backup. Changes in most sections are applied after pressing Save Settings at the bottom ("Settings saved successfully").

14.1. AI models

Lexora splits AI work into roles, and a model is chosen for each. Roles are grouped:

GroupRoles
TextFast translation; Quality text (writing, explanations).
ImagesImage translation (vision).
VoiceSpeech recognition; Live dialogue; Live interpreting; Text-to-speech.
IllustrationsAI pictures for words (paid, ≈ $0.03 per picture; off by default — free photos are used instead).

The state of each role is shown by a label: "Работает" (Working), "Нужен ключ" (Key needed), "Выключено" (Off), "Не настроено в этом пакете" (Not set up in this package). The Проверить (Check) button sends a test request.

Advanced: a model for each role

The collapsible block "Расширенные: модель для каждой роли" (Advanced: model per role) lets you set a model for each role and a chain of fallbacks: if the primary is unavailable or rate-limited, Lexora switches to the next one.

14.2. AI usage

A table for 7 or 30 days: role, model, volume (requests or live-voice minutes), errors and a cost estimate. Counters are stored only on this computer. The estimate uses published prices of paid features (AI pictures, live-voice minutes); text, photo and voice within the Gemini free tier are not billed. Speech playback is cached and not counted.

14.3. Language Preferences

  • Learning language (source) — the language you study. TTS, pronunciation, writing check and word packs use it.
  • Translation language (target) — the language words are translated into (your native one).

14.4. Privacy

  • Writing privacy mode — texts from the Writing Assistant are not stored; no history or error patterns are collected.
  • Writing auto-check — auto-check after you pause typing (uses AI and may cost money).

14.5. Writing check in other apps

  • The Suggest fixes while I type in any app toggle enables background checking (see section 13). On first enable, grant the Accessibility permission.
  • Never check in these apps — an exclusion list (bundle ID on macOS or the .exe name on Windows); Add adds an app. An app can also be excluded in one click from the fix panel.

14.8. Backup / Export

Export vocabulary saves your vocabulary (words, translations, notes and SRS progress) to a JSON file. Import vocabulary restores it on another computer; existing words are not overwritten on import.

15. Data, backups and privacy

  • Where data is stored. In the SQLite file lexora.db in the app data directory (WAL mode). All writes are transactional.
  • Integrity check. On every launch. If the database is corrupt, the file is not deleted but renamed to lexora.db.corrupt-<time>, and the app recovers from the most recent automatic copy.
  • Automatic copies. Stored in the backups/ subfolder of the data directory (lexora-backup-…); several recent ones are kept and older ones are deleted automatically.
  • Manual export. Settings → Backup → Export vocabulary (JSON).
  • Caches. Word pictures and speech audio are cached locally and not requested again.
  • What goes over the network. Only requests to the AI provider you chose (text for translation/checking, audio for recognition, pictures) and requests for free photos. No analytics or telemetry. In "No AI" mode the network is not used.
  • API keys. Stored via tauri-plugin-store (not in plain text), or taken from environment variables.
  • Window security. A CSP without unsafe-eval is configured, external HTML is sanitized with DOMPurify, and SQL uses parameterized queries only.
