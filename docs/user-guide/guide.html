1. О приложении и основные принципы

Lexora — настольное приложение (Tauri 2 + React + Rust, база SQLite) для изучения иностранных языков. Вы собираете личный словарь, повторяете слова по алгоритму интервальных повторений SM-2, пишете и переводите тексты с помощью AI, тренируете произношение и разговариваете с AI-собеседником.

Local-first. Словарь, повторения и статистика работают полностью офлайн. Интернет нужен только для AI-функций (перевод, проверка текста, голос).
Privacy by design. Никакой аналитики и телеметрии. Данные хранятся только на вашем компьютере; счётчики расхода AI — тоже локально.
Детерминированные повторения. Одни и те же ответы всегда дают одну и ту же дату следующего повторения (SM-2).
Без потерь данных. Все записи в БД транзакционные, при старте проверяется целостность базы, есть автоматические копии и экспорт в JSON.

Мастер первой настройки

При первом запуске, пока AI не настроен, автоматически открывается мастер «Как настроить Lexora?». Он выбирает пакет моделей за вас — вручную настраивать каждую роль не нужно.

  • Бесплатно — без карты. Один бесплатный ключ Google Gemini (получить на aistudio.google.com → Get API key) включает AI-перевод, перевод фото и голоса, живой диалог и синхронный перевод. Можно и совсем без ключей: встроенный словарь, свободные фото (Wikimedia) и системный голос. Также доступен бесплатный вариант Cloudflare Workers AI.
  • Платно — один ключ OpenAI или Gemini с оплатой по использованию: всё из бесплатного плюс AI-иллюстрации к словам.

Сценарий можно сменить позже: Settings → AI-модели → «Сменить сценарий».

3. Быстрый старт за 5 шагов

  1. Выберите сценарий AI в мастере (рекомендуется Google Gemini — бесплатный ключ) и вставьте ключ.
  2. Задайте язык изучения и язык перевода: Settings → Language Preferences.
  3. Добавьте слова: Vocabulary → Add Word (по одному), Paste list (списком) или загрузите готовый набор в Collections.
  4. Занимайтесь: Study → выберите режим → Start Session. Оценивайте себя кнопками Again / Hard / Good / Easy — приложение само запланирует следующее повторение.
  5. Включите фоновые инструменты: хоткей ⌘⇧L для перевода выделенного текста и ⌘⇧S для стикеров (Windows/Linux: Ctrl+Shift+L / Ctrl+Shift+S).
Если вы вообще не хотите настраивать AI, приложение остаётся рабочим: словарь, повторения и статистика полностью офлайн.

4. Интерфейс: навигация

Слева — боковая панель с основными разделами. У пункта Study красный счётчик показывает, сколько карточек нужно повторить сегодня. Внизу — Settings. Окно можно скрыть: приложение остаётся в системном трее/строке меню.

Интерфейс тёмный, управляется мышью и клавиатурой (есть ссылка «Skip to main content», видимый фокус, ARIA-метки).

5. Vocabulary — личный словарь

Таблица слов с колонками: Word (слово и транскрипция), Translation, Type (часть речи), Frequency (ранг частотности), Status и Due (когда следующее повторение). Список виртуализирован — большие словари (тысячи слов) прокручиваются без задержек.

  • Поиск по слову и переводу — строка «Search words…».
  • Фильтры по статусу: All · New · Learning · Review · Mature.
  • Study Now — сразу перейти к повторению.
  • ▶ звук рядом со словом — озвучка (TTS кэшируется локально).

Статусы слов

СтатусЗначение
NewСлово добавлено, ещё не повторялось.
LearningИнтервал 1–4 дня.
ReviewИнтервал 4–21 день.
MatureИнтервал более 21 дня — слово закрепилось.

Добавление слов

Кнопка Add Word и стрелка рядом с ней открывают меню из трёх способов:

  1. Add one — введите слово или фразу, нажмите Translate: Lexora подберёт перевод, транскрипцию, часть речи, примеры и (если включено) картинку. В поле «Personal notes» можно записать контекст или мнемонику. Кнопка Add to Vocabulary сохраняет слово. Язык перевода выбирается в окне (сессионная настройка, глобальную не меняет).
  2. Paste list — вставьте слова по одному на строку (до 100 записей за раз). Переводятся в фоне.
  3. Upload file — загрузка списка слов из файла.

Карточка слова

Клик по строке открывает панель справа: слово, транскрипция, часть речи, частотность, статус, перевод и его альтернативы, иллюстрация, SRS-данные (Interval, Ease Factor, Repetitions), личные заметки (Save Notes). Здесь же: избранное (звезда), Practice pronunciation (переход в Speak с этим словом), обновление картинки и Remove from vocabulary.

6. Study — повторения (SRS)

Экран «Study Session» показывает, сколько карточек пора повторить, и 8 режимов. Выберите режим, нажмите Start Session. Сверху — прогресс сессии («Card 1 of 5»), внизу — «Due today», «Accuracy» и «Time».

Алгоритм

Используется SM-2 — чистая детерминированная функция. После каждого ответа выставляется оценка (0 — полный провал … 4 — легко), и пересчитываются интервал, коэффициент лёгкости (ease) и дата следующего повторения. Ошибка возвращает слово в короткий интервал и увеличивает счётчик «lapses» — по ним строятся «самые трудные слова» в статистике.

8 режимов

РежимКак работает
FlashcardsКлассические карточки: слово → вариант перевода из нескольких (или «Show Answer», Space) → самооценка Again / Hard / Good / Easy. Справа панель «Context» с примером.
Typing ModeПоказывается перевод — вы вводите слово. Проверка по Enter, ошибки в написании объясняются.
ListeningСлышите слово и печатаете то, что услышали.
Fill the GapПредложение с пропуском; AI может объяснить ошибку.

Irregular VerbsТренировка форм Past Simple и Past Participle.
DefinitionОпределение и синонимы → вспомнить слово.
SpeakingПроизнести слово вслух; оценка по фонемам с обратной связью.

В конце сессии появляется итог; кнопка Back to Study Overview возвращает к выбору режима. Режимы «Irregular Verbs» и «Image Association» работают с подходящими словами из вашего словаря (глаголами и словами с картинками).

7. Writing — помощник по письму

Вставьте текст (до 8000 символов) и нажмите Check writing. Lexora оценивает текст (балл 0–100), подсвечивает ошибки, показывает исправленный вариант и объясняет каждое замечание (категория, правило).

  • Apply / Accept all — принять одно исправление или все. Copy — копировать исправленный текст, Use as input — подставить его как новый ввод.
  • Auto-check (переключатель сверху) — проверять автоматически после паузы в наборе. Тратит запросы к AI.
  • Rewrite — переписать текст: Clearer, Shorter, More formal, Friendlier, Professional, Simpler.
  • Your Error Patterns — типичные ваши ошибки (например, «she go → she goes ×3»). Кнопка Generate Exercises создаёт упражнения именно на них.
Режим Writing privacy mode (Settings → Privacy) не сохраняет проверяемые тексты и не собирает паттерны ошибок.

8. Translate — центр перевода

Вверху — выбор исходного языка (по умолчанию Auto-Detect), кнопка смены направления ⇄, целевой язык и режим «Smart». Шесть вкладок:

ВкладкаЧто делает
TextПеревод текста. Тон: Standard / Formal / Casual / Academic. Озвучка исходного и перевода, копирование, Save to Vocabulary (сохранить как слово/карточку), альтернативные формулировки.
Image & PhotoПеревод картинок и скриншотов: перетащите файл (PNG, JPG, WebP), выберите через диалог или вставьте из буфера ⌘V. Режимы просмотра: In-Place Overlay (перевод поверх картинки), Side-by-Side, Extracted Text.
DocumentДокументы и PDF: .pdf .docx .md .txt .srt .vtt. Двухпанельный редактор «оригинал / перевод», глоссарий терминов, тон. Результат можно скачать.
Speech & AudioЗапись с микрофона (Record) или загрузка аудиофайла (File Upload): распознавание речи и перевод; фразы можно добавить в словарь.
Live InterpreterСинхронный перевод: говорите на любом языке — в ответ звучит перевод. Опция «Speak the translation aloud». Сессия до 15 минут, транскрипт сохраняется в историю. Нужен ключ провайдера с живым голосом (Gemini).
HistoryИстория переводов с фильтрами All / Text / Image / Document / Audio, избранное, копирование, удаление записи и «Clear History».

9. Speak — тренер произношения

Четыре вкладки: Practice, Shadowing, Minimal pairs, History. Результат оценивается в баллах (0–100) и по фонемам; зачёт — от 90%.

Practice

Введите слово или фразу (можно задать целевую транскрипцию IPA). Listen to Model — эталонное произношение, Voice — выбор голоса, Say / Record — запись (или удерживайте Space). После записи показываются «Current Score» и итог сессии «Total Session Score». Нажмите на проблемную фонему, чтобы получить подсказку по артикуляции (например, «Close both lips…»). Next Phrase — следующая фраза.

Shadowing

Фраза берётся из вашей очереди повторений. Слушаете образец и сразу повторяете вслед (Say phrase → «Speak now» → Stop recording); сравниваются волны речи, итог — «Passed» или нет.

Minimal pairs

Пары слов, отличающиеся одним звуком (ship / sheep, /ɪ/ vs /iː/). Прослушайте оба (Listen), затем произнесите целевое слово — получите оценку попадания. Контраст можно выбрать в списке справа вверху.

History

Список прошлых попыток с оценкой; по ним формируется блок «Problem sounds» (самые проблемные звуки) — он же виден в Stats.

10. Dialogue — AI-диалог

Слева вверху вкладки AI Dialogue и Practice Scenarios. Выберите сценарий с уровнем (например, «Coffee Shop in London (B2 Level)»). AI-собеседник открывает разговор первой репликой и ведёт диалог в роли (бариста, продавец и т. п.).

  • Record & send — записать реплику голосом: удерживайте Space, отпустите — реплика отправится (Say / Send).
  • Live conversation — режим живого голосового диалога (нужен провайдер с realtime-голосом — Gemini Live).
  • Type a reply instead — ответить текстом.
  • Справа — Current Turn Score (оценка реплики), Total Session Score (Fluency & Clarity) и Live vocabulary suggestions — подходящие выражения для сценария.

11. Collections — наборы слов

Готовые («system») наборы для изучаемого языка: Top 5000 Words, Phrasal Verbs, Irregular Verbs, Business English, Academic English, Travel English. Набор сначала нужно загрузить в базу, затем включить в SRS:

  1. Load into database — загрузка слов набора (для Top 5000 это ~5000 слов). Галочка «Also fetch pictures when loading a pack» дополнительно подтянет картинки (медленнее, использует провайдера картинок).
  2. Enable in SRS / «Active in SRS» — включить или отключить набор в повторениях.

+ New Collection создаёт собственную коллекцию (название и описание).

Наборы можно использовать и как источник для стикеров на рабочем столе (Settings → Stickers).

12. Stats — статистика

  • Total Vocabulary — всего слов; Accuracy — процент правильных ответов; Mature Words — слова с интервалом > 21 дня; Current Streak — серия дней подряд с повторением.
  • Words Added — добавлено сегодня / за неделю / за месяц / всего.
  • Activity — Last 30 Days — диаграмма: повторения (синие) и добавленные слова (зелёные) по дням.
  • Accuracy by Error Type — точность по типам ошибок (грамматика, орфография…).
  • Hardest Words — слова с наибольшим числом ошибок и низкой точностью.
  • SRS Mastery Stages — New / Learning / Review / Mature.
  • Writing Mistake Patterns и Pronunciation — типичные письменные ошибки и проблемные звуки.

13. Работа вне главного окна

Popup-переводчик

Выделите текст в любом приложении (браузер, PDF, заметки) и нажмите ⌘⇧L (Windows: Ctrl+Shift+L). Откроется всплывающее окно с переводом, транскрипцией, синонимами, частотностью, картинкой и примерами. Текст берётся только из выделения, никогда из буфера обмена. Окно закрывается по Esc.

  • + Add Word — сохранить слово в словарь (кнопка меняется на «✓ Added to Vocabulary»).
  • 🔊 — озвучка, закладка — сохранить в историю, Translate/Enter — перевести введённый вручную текст.
  • Выбор исходного/целевого языка и режима («Auto» / «Smart») прямо в окне.
  • Если выделен длинный текст, окно работает как встроенный AI-ассистент: можно принять и заменить текст в приложении (accept and replace).

Стикеры на рабочем столе

Небольшие полупрозрачные карточки поверх рабочего стола для фонового повторения. На карточке — слово и транскрипция; перевод скрыт (кнопка с глазом показывает его). Оцените себя:

  • Помню ✓ — слово запоминается; Не помню ✕ — вернётся скорее; Позже — отложить. После ответа карточка исчезает и сменяется следующей.
  • Верхние кнопки: озвучка, показать перевод, цитата-пример, фильтр источника слов, закрепить поверх окон (pin), закрыть.

Показать/скрыть все стикеры: ⌘⇧S или пункт «Toggle Stickers» в меню трея. Количество, прозрачность, источники слов и «тихие часы» — Settings → Stickers.

Меню в трее

Значок Lexora в строке меню (macOS) / системном трее: Open Lexora, Open Translator (пустое окно переводчика, ничего не берётся из буфера), Translate Selection, Toggle Stickers, Quit. Также на macOS перевод выделенного текста доступен через правый клик → Services → Lexora.

Проверка текста в других приложениях («как Grammarly»)

Включается в Settings → «Writing check in other apps» (по умолчанию выключено; macOS и Windows; нужно то же разрешение Accessibility).

  • Lexora следит за текстовым полем, в котором вы печатаете. Через ~0,7 с после паузы текст отправляется AI-провайдеру на проверку на изучаемом языке.
  • В углу поля появляется бейдж с числом замечаний.
  • Клик по бейджу открывает панель с карточками исправлений; Apply меняет текст прямо в поле (сначала точечно через Accessibility — сохраняются форматирование и undo; если приложение не принимает запись — через буфер). Если вы успели изменить текст после проверки, исправление не применяется. Dismiss отклоняет замечание, Esc закрывает панель.
  • Не читаются: поля паролей, поисковые поля, приложения из списка исключений (менеджеры паролей, терминалы, IDE — редактируется в настройках), тексты не на изучаемом языке. Проверки не сохраняются в БД.

14. Настройка приложения (Settings)

Страница настроек — один длинный экран с верхней панелью быстрых переходов: AI models · AI usage · Language · Privacy · Writing check · Stickers · Shortcuts · Backup. Изменения в большинстве разделов применяются после нажатия Save Settings внизу страницы (сообщение «Settings saved successfully»).

14.1. AI-модели

Lexora разделяет работу AI на роли, и для каждой выбирается модель. Роли сгруппированы:

ГруппаРоли
ТекстБыстрый перевод; Качественный текст (письмо, объяснения).
КартинкиПеревод картинок (vision).
ГолосРаспознавание речи; Живой диалог; Синхронный перевод; Озвучка (TTS).
ИллюстрацииAI-картинки к словам (платно, ≈ $0.03 за картинку; по умолчанию выключено — подбираются свободные фото).

Состояние каждой роли показывается меткой: «Работает», «Нужен ключ», «Выключено», «Не настроено в этом пакете». Кнопка Проверить делает тестовый запрос.

Пакет — готовый набор маршрутов для всех ролей: один ключ закрывает всё.

Расширенные: модель для каждой роли

Раскрывающийся блок «Расширенные: модель для каждой роли» позволяет задать для каждой роли свою модель и цепочку резервных (fallback): если основная недоступна или упёрлась в лимит, Lexora переключается на следующую.

14.2. Расходы AI

Таблица за 7 или 30 дней: роль, модель, объём (запросы или минуты живого голоса), ошибки и оценка стоимости. Счётчики хранятся только на этом компьютере. Оценка считается по опубликованным ценам платных функций (AI-картинки, минуты живого голоса); текст, фото и голос в бесплатном тарифе Gemini не оплачиваются. Озвучка кэшируется и не учитывается.

14.3. Language Preferences

  • Learning language (source) — изучаемый язык. По нему работают TTS, произношение, проверка письма и наборы слов.
  • Translation language (target) — язык, на который переводятся слова (ваш родной).

14.4. Privacy

  • Writing privacy mode — тексты из Writing Assistant не сохраняются, история и паттерны ошибок не собираются.
  • Writing auto-check — автопроверка после паузы в наборе (использует AI и может стоить денег).

14.5. Writing check in other apps

  • Переключатель Suggest fixes while I type in any app — включает фоновую проверку (см. раздел 13). При первом включении выдайте разрешение Accessibility.
  • Never check in these apps — список исключений (bundle ID на macOS или имя .exe на Windows); кнопка Add добавляет приложение. Из панели исправлений приложение можно исключить «одним кликом».

14.8. Backup / Export

Export vocabulary сохраняет словарь (слова, переводы, заметки и SRS-прогресс) в JSON-файл. Import vocabulary восстанавливает его на другом компьютере; существующие слова при импорте не перезаписываются.

15. Данные, резервные копии и приватность

  • Где хранятся данные. В SQLite-файле lexora.db в каталоге данных приложения (режим WAL). Все записи делаются транзакциями.
  • Проверка целостности. При каждом запуске. Если база повреждена, файл не удаляется, а переименовывается в lexora.db.corrupt-<время>, и приложение восстанавливается из самой свежей автоматической копии.
  • Автокопии. Лежат в подпапке backups/ каталога данных (lexora-backup-…), хранится несколько последних, старые удаляются автоматически.
  • Ручной экспорт. Settings → Backup → Export vocabulary (JSON).
  • Кэши. Картинки к словам и озвучка кэшируются локально и не запрашиваются повторно.
  • Что уходит в сеть. Только запросы к выбранному вами AI-провайдеру (текст для перевода/проверки, аудио для распознавания, картинки) и запросы за свободными фото. Аналитики и телеметрии нет. В режиме «Без AI» сеть не используется.
  • Ключи API. Хранятся через tauri-plugin-store (не в открытом виде), либо берутся из переменных окружения.
  • Безопасность окна. Настроена CSP без unsafe-eval, внешний HTML очищается DOMPurify, SQL — только параметризованные запросы.

17. Решение проблем

ПроблемаЧто делать
macOS не открывает приложение («неизвестный разработчик»)Запустите Разрешить Lexora.command из DMG либо Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».
Хоткей открывает popup, но выделенный текст не подставляетсяВыдайте Lexora разрешение Accessibility и перезапустите приложение.
В AI-моделях «Нужен ключ»Вставьте ключ пакета и нажмите «Сохранить», затем «Проверить» у роли. Бесплатный ключ Gemini: aistudio.google.com → Get API key.
Не работает Live Interpreter / живой диалогЭти роли доступны только у провайдеров с realtime-голосом (сейчас Gemini). Для OpenAI/Cloudflare/Ollama используйте записанную речь или текст.
Перевод фото или речи недоступенAnthropic и Cloudflare не поддерживают аудио/vision в этой конфигурации — выберите пакет Gemini или OpenAI.
Стикеры не появляютсяПроверьте «Тихие часы», количество стикеров и источник слов (должны быть слова к повторению); переключите ⌘⇧S.
Бейдж проверки в других приложениях не появляетсяВключите функцию в Settings, дайте Accessibility; поле не должно быть паролем/поиском и приложение не в списке исключений; язык текста должен совпадать с изучаемым.
«Хочу работать без интернета»Выберите пакет «Без AI»: словарь, повторения, статистика и системная озвучка работают офлайн.
База поврежденаLexora восстановится из автокопии сама. Повреждённый файл сохраняется как lexora.db.corrupt-…. Можно также импортировать ранее экспортированный JSON.
