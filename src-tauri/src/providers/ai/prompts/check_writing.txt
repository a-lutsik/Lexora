{text}

Return strict JSON:
{
  "issues": [ ... ],
  "overall_score": <0-100 integer quality score>,
  "summary": "<brief 1-sentence overall assessment>"
}

- offset_start and offset_end must precisely match original_fragment: input.substring(offset_start, offset_end) === original_fragment.

- suggested_fix replaces ONLY original_fragment — do not include neighbouring letters.
